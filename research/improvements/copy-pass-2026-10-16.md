# Copy + accessibility pass, 2026-10-16

Text-only copy changes (no numbers, cut-offs, evidence levels or sources changed) plus WCAG 2.2 AA work. Backup of every touched file: `backups/20261016-153558-copy-a11y/`.

## Terminology chosen (one term per concept)

- Status scale: **Fine · Mild stress · High stress** (replaces Good/working well, overload/overloaded). Heart red now reads "your heart is working harder for now".
- **Blood sugar** in user text (not "glucose"/"sugar"); event name **Blood sugar peak** (replaces Sugar rush / sugar spike); **Blood sugar dip**.
- Blood alcohol always shown in **‰** in the UI (= g/L; HowWeKnow now explains this). Evidence claims keep the study unit g/L.
- Evidence link everywhere: **How do we know?**; methodology page: **How we know**; colours link: **How the colours work**.
- British spelling kept throughout (colour, fibre, glycaemic, oesophagus). Sentence case on buttons. En dash for ranges, × for portions, "about" instead of "≈" inside sentences.
- Time slider and "Had it at" wording: "Time since you had it", "Had it at" (was Drunk at / Time after eating / Time after drinking).

## Fixes asked for

- Answers.tsx driving answer: "real values differ by up to 40%" → "The range runs from 40% below to 50% above our estimate, because bodies differ." (matches ranges.ts −40%/+50%). HowWeKnow ranges paragraph corrected the same way.
- Beer chapter vs body label: chapters can now carry `live(m)` text (stories.ts `chapterText`). "Alcohol peak" and alcohol "Bedtime" chapters format the value at the current minute with the same `bacRangeText` as the body label (routes.ts). Every place that shows chapter text (StoryPanel, CalmBar, video caption, compare video, moment card) uses it. The video "pop" number now uses the same interpolated minute too. New test in routes.test.ts checks label = chapter text at several minutes.
