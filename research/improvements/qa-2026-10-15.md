Where the time goes: the shell already paints at ~0.35 s on Slow 4G (the bundle is at the end of body); 5.2 s is downloading 2.5 MB **uncompressed** (gzip = 1.07 MB → ~2.3 s on a host that compresses, e.g. Netlify/Cloudflare do by default); ~0.9 s parse/eval at 4x CPU; the rest are long tasks from the 3D (WebGL test context 276 ms, tube geometry ~200 ms, model decode + shader compile up to ~1 s on SwiftShader). Locally (no throttling) the UI is up in < 0.7 s; the 7.6 / 11.3 s in the first QA came from software GL rendering at 60 fps behind the start screen, which this pass stops.
